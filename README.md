# Eminence Shire Hotel

A responsive, multi-page hotel and wellness website for Eminence Shire Hotel in Pitigala, Galle District, Sri Lanka. The content highlights eco-friendly hospitality, organic wellness, mountain views, Sinharaja, local cinnamon/tea/rubber landscapes, Ambalangoda craft and Galle. Built with vanilla JavaScript and Vite using illustrative locally stored visual assets.

## Run locally

```sh
npm install
npm run dev
```

## Pages and interactions

- Home, philosophy, accommodation, wellness, dining, destination and gallery views
- Responsive desktop navigation and full-screen mobile menu
- Gallery category filters and image lightbox
- Booking enquiry dialog with date validation
- Newsletter form feedback and back-to-top control

Booking and contact enquiries open the visitor’s email app with the information entered. The newsletter form is a front-end demo and is not connected to a mailing-list service.
